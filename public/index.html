Objective changes

  • Activity has decreased.

Context

Measured labs

TSH 4.8 (previous 2.9); ferritin 18 (previous 31); HbA1c 5.4%.

Interpretation boundary

Pattern warrants clinical review. This system does not diagnose or independently order tests.
